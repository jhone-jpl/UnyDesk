# UnyDesk Console

Proprietary web console (React + Vite) for UnyDesk management.

Uses **@uny/design-system** (`/srv/projects/UnyDesignSystem`) for tokens/theme and the Uny shell pattern (sidebar, topbar, ThemeCustomizer).

Default login (API): `admin` / `UnyDesk!admin`

```bash
npm install
npm run dev
```

Opens on http://localhost:5173 and proxies `/api` to the API on `:21114`.
