# AGPL source offer — UnyDesk client

The UnyDesk remote desktop **client** is free software under the GNU Affero
General Public License v3.0. Corresponding source is the `unydesk-client/`
tree in this project (derivative of RustDesk 1.4.9).

To obtain the source that matches a binary you received from Unysystems:

1. Clone / request this repository, or
2. Contact Unysystems with the client version string (Help → About / `--version`).

The management API and web console are **not** AGPL and are not covered by
this offer.
